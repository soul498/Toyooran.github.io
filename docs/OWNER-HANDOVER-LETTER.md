# نامه و راهنمای تحویل سایت و سرور «طیوران صنعت پویا (TSPK)»

**از طرف:** مدیریت پروژه طیوران صنعت پویا (`https://www.toyooran.com`)  
**خطاب به:** برنامه‌نویس / متخصص فنی جدید پروژه  

سلام و وقت بخیر،

این سند را برای شما آماده کرده‌ام تا بدون ابهام و بدون نیاز به آزمون و خطا، کل ساختار سرور، کدهای سایت، قوانین سئو و نحوهٔ ویرایش و دیپلوی پروژه **طیوران صنعت پویا** را تحویل بگیرید. لطفاً قبل از هرگونه تغییر در کد یا سرور، این راهنما و فایل‌های معرفی‌شده را به ترتیب مطالعه کنید.

---

## ۱. از کجا شروع کنید؟ (ترتیب مطالعهٔ اجباری در ۱۵ دقیقه اول)

وقتی وارد سرور شدید، به مسیر اصلی پروژه بروید:
```bash
cd /opt/Toyooran
```

تمام مستندات فنی و اسکیل‌های کمکی در پوشهٔ `docs/` قرار داده شده‌اند. **حتماً به این ترتیب بخوانید:**

1. **`AGENTS.md` (در ریشهٔ پروژه):** خلاصهٔ ۱ دقیقه‌ای قوانین طلایی سرور و گیت.
2. **`docs/HANDOVER-GUIDE.md` (مهم‌ترین سند):** راهنمای صفر تا صد معماری سرور، سرویس‌های Docker، دیتابیس SQLite، نحوهٔ ادیت بخش‌های مختلف، ساخت توکن API محتوا و دستورات عیب‌یابی اضطراری.
3. **`docs/source-map.md`:** نقشهٔ کامل فایل‌های پروژه؛ به شما می‌گوید برای تغییر هر بخش از سایت سراغ کدام فایل بروید.
4. **`docs/ci-cd.md`:** نحوهٔ کارکرد گیت محلی (Forgejo) و اسکریپت دیپلوی خودکار.
5. **`docs/seo/SEO-CONTRACT.md` و `docs/seo/README.md`:** قوانین تغییرناپذیر سئوی سایت که هیچ تغییری در ظاهر (UI) نباید آن‌ها را خراب کند.
6. **`docs/skills/toyooran-maintainer/SKILL.md` (و `.cursor/skills/toyooran-maintainer/SKILL.md`):** اگر از ابزارهای هوش مصنوعی (مثل Cursor یا Claude) برای توسعه استفاده می‌کنید، این اسکیل آماده است تا ایجنت دقیقاً طبق قوانین سایت کار کند.

## ۲. قوانین طلایی پروژه (خط قرمزهایی که باید رعایت شوند)

1. **فقط شاخهٔ `main` در گیت محلی (Forgejo):**
   - سورس اصلی پروژه روی گیت محلی همین سرور (`origin` -> `http://127.0.0.1:3002/mhzare/toyooran.git` یا `https://git.toyooran.com/mhzare/toyooran.git`) است.
   - ریموت `github` فقط یک آرشیو قدیمی است؛ **اصلاً از GitHub برای پوش یا دیپلوی استفاده نکنید.**
   - همهٔ کامیت‌ها مستقیم روی شاخهٔ **`main`** انجام می‌شوند. شاخهٔ جدید (Branch) نسازید.
2. **نحوهٔ دیپلوی (انتشار روی سایت):**
   - هر زمان روی `main` کامیت کردید و دستور `git push origin main` را زدید، سرویس Forgejo Actions روی همین سرور به صورت خودکار اسکریپت `/usr/local/sbin/toyooran-deploy.sh` را اجرا می‌کند و ظرف حدود ۴۵ ثانیه سایت آپدیت می‌شود.
   - قبل از شروع کار و قبل از هر پوش، همیشه `git fetch origin main && git rebase origin/main` بزنید.
   - اگر زمانی خواستید دستی دیپلوی کنید: `/usr/local/sbin/toyooran-deploy.sh`
   - اگر مشکلی پیش آمد و خواستید به نسخهٔ سالم قبلی برگردید: `/usr/local/sbin/toyooran-rollback.sh`
3. **حفظ کامل سئو (SEO Prerender):**
   - سایت با React 19 و Express 5 نوشته شده است. سرور در لحظهٔ درخواست، تگ‌های سئو، اسکیما (JSON-LD) و محتوای کامل متنی را در `#seo-prerender` داخل HTML اولیه تزریق می‌کند (`server/seo.ts` و `src/seo/resolveSeo.ts`).
   - هرگز پیش‌رندر سروری، Canonicalها یا ساختار تگ `<h1>` صفحات را حذف یا غیرفعال نکنید.
4. **پشتیبانی از مرورگرهای قدیمی و تلویزیون هوشمند:**
   - سایت روی تلویزیون‌های هوشمند (Android TV با Chrome نسخه 98) هم نمایش داده می‌شود. از افکت‌ها یا CSSهایی که روی مرورگرهای قدیمی صفحه را خراب می‌کنند استفاده نکنید و منطق `isLiteDevice()` در `src/lib/device.ts` را حفظ کنید.
5. **دیتابیس و داده‌های پایدار بیرون از کانتینر هستند:**
   - دیتابیس SQLite در مسیر `/opt/toyooran-data/toyooran.sqlite` و فرم‌های تماس مشتریان در `/opt/toyooran-data/qualified-leads.jsonl` ذخیره می‌شوند. بکاپ‌های خودکار هم در `/opt/toyooran-data/backups/` هستند.

## ۳. وضعیت فعلی بخش‌های مهم سایت (تصمیماتی که قبلاً گرفته شده و باید حفظ شوند)

- **لوگوی سایت:** نشان بدون متن زیرین (`/images/logo-mark.png` و `/images/logo-new.png`) در هدر، منوی موبایل، فوتر و فاوآیکون تنظیم شده است.
- **ویترین صفحهٔ اصلی (`src/components/CompactShowcase.tsx`):**
  - در بالای این بخش، نوار **«دسته‌های تجهیزات دام و طیور»** قرار دارد.
  - در پایین آن، کارت اسلایدر **«محصولات پرفروش»** است که ۴ محصول پرفروش + ۱۲ محصول پرکاربرد (مجموعاً ۱۶ اسلاید) را نمایش می‌دهد و کنار آن ستون **«مجله تخصصی»** قرار دارد.
  - *نکته:* قبلاً یک باکس متنی جداگانه برای لینک‌های سئو زیر این بخش بود که حذف و داخل همین ویترین ادغام شده است؛ آن باکس قدیمی نباید برگردد.
- **صفحهٔ محصولات (`/products`):**
  - بنر بالای صفحه در `src/components/ShopHero.tsx` است و متن دکمهٔ دانلود فایل PDF کاتالوگ، دقیقاً **«دانلود کاتالوگ»** است.
- **لوکیشن‌ها و نقشه‌ها:**
  - در کل سایت **فقط ۲ لوکیشن** باید نمایش داده شود (`src/data/mockData.ts`):
    1. **دفتر مرکزی مشهد:** مشهد، میدان مادر، مجتمع تجاری ادیب، طبقه ۳، واحد ۴۰۶
    2. **دفتر تحقیق و توسعه:** گرگان، بلوار بهشتی
  - نقشه‌ها به صورت iframe از **بلد (`balad.ir`)** هستند و دکمهٔ **«مشاهده نقشه»** هم مستقیم به صفحهٔ همان لوکیشن در سایت بلد باز می‌شود (`src/lib/baladMaps.ts`). لوکیشن‌های قدیمی (مثل کارخانه میثاق یا کارخانه نوآوری) حذف شده‌اند و نباید اضافه شوند.

## ۵. چک‌لیست تست قبل از هر انتشار (Deploy)

هر زمان تغییری در کد دادید، قبل از کامیت و پوش حتماً این ۳ دستور را در `/opt/Toyooran` اجرا کنید و مطمئن شوید بدون خطا (`ok`) تمام می‌شوند:

```bash
cd /opt/Toyooran
npm run lint              # بررسی خطاهای TypeScript
npm run test:legacy-spam  # تست عملکرد صحیح فیلتر لینک‌های اسپم (410)
npm run check:seo         # تست کامل سلامت سئو، Canonical، Sitemap و رندر سرور
```

سپس تغییرات را روی `main` کامیت و به `origin main` پوش کنید:
```bash
git add .
git commit -m "توضیح تغییر انجام‌شده"
git push origin main
```

برای هر جزئیات بیشتر (مثل نحوهٔ ساخت توکن جدید برای API محتوا یا بازیابی بکاپ دیتابیس)، به فایل **`docs/HANDOVER-GUIDE.md`** مراجعه کنید.
