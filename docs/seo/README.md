# SEO Operating System — طیوران صنعت پویا

این پوشه مرجع واحد سئو برای انسان و ایجنت است. تصمیم متناقض با این اسناد بدون
ثبت دلیل و تأیید مالک SEO اجرا نشود.

## ترتیب مطالعه

1. `SEO-CONTRACT.md` — invariantهای فنی و معماری فعلی
2. `CONTENT-STRATEGY.md` — انتخاب موضوع، تولید، بازبینی و انتشار
3. `CONTENT-BRIEF-TEMPLATE.md` — Brief اجباری هر محتوا
4. `CONTENT-BACKLOG.md` — صف شروع و محتوای Blocked
5. `CHANGELOG.md` — تاریخچه تغییرات عمومی سئو

## هدف کسب‌وکار

SEO باید Lead واجد شرایط سراسری برای **تجهیز و نوسازی سالن مرغداری** بسازد.
اعتبار پروژه‌ها و دفاتر واقعی مشهد/گرگان پشتوانه اعتماد است؛ هدف ساخت ترافیک
عمومی یا انتشار انبوه مقاله نیست.

## الگوریتم اولویت

اولین شرط باز را ببند؛ پایین‌تر نرو:

1. محتوای اصلی در HTML اولیه نیست → SSR/SSG/Prerender
2. canonical/redirect/sitemap ناسازگار است → یکسان‌سازی
3. صفحه پول‌ساز H1/title/description/URL مستقل ندارد → اصلاح
4. صفحه Product/Service/Article Schema سروری ندارد → افزودن
5. صفحه تجاری پوشش Intent یا CTA ندارد → تکمیل
6. مقاله بدون نویسنده، بازبین، منبع، تجربه و لینک داخلی است → بازنویسی
7. فقط سپس محتوای جدید با Brief تأییدشده تولید شود

## مالکیت

- مالک SEO: Keyword map، Intent، URL، metadata، Schema و اولویت Backlog
- توسعه‌دهنده: rendering، routing، redirects، performance و انتشار امن
- متخصص موضوعی شرکت: صحت محاسبه، ادعا، مشخصات و نتیجه پروژه
- نویسنده: تحقیق، Draft، استناد و اصلاح طبق Brief
- مدیر فروش: CTA، اعتراضات مشتری و کیفیت Lead

## معیار موفقیت

North Star تعداد مقاله یا بازدید نیست:

`Organic Qualified Lead → Proposal → Closed-Won`

شاخص‌های کمکی: صفحات معتبر ایندکس‌شده، non-brand clicks، CTR، Top-10 intentهای
تجاری، نرخ تبدیل صفحه، Core Web Vitals و Lead source ثبت‌شده در CRM.
